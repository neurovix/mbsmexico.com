# mbsmexico.com 🏗️

Sitio web oficial de **MBS México**, empresa constructora con sede en Monterrey, Nuevo León, México.

---

## 🌐 Descripción

Este repositorio contiene el código fuente del sitio web corporativo de MBS México. El sitio fue diseñado y desarrollado para presentar los servicios, proyectos y presencia digital de la empresa en el sector de la construcción.

## 🛠️ Tecnologías utilizadas

- **[Astro.js](https://astro.build/)** — Framework web moderno orientado al rendimiento y generación de sitios estáticos.
- **[Tailwind CSS](https://tailwindcss.com/)** — Framework de CSS utilitario para un diseño rápido y consistente.

## 🚀 Instalación y uso

### Prerrequisitos

- Node.js `>= 18.x`
- npm o pnpm

### Pasos

```bash
# Clonar el repositorio
git clone https://github.com/neurovix/mbsmexico.com.git

# Entrar al directorio
cd mbsmexico.com

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar build de producción
npm run build

# Previsualizar build de producción
npm run preview
```

## 📁 Estructura del proyecto

```
mbsmexico.com/
├── public/          # Archivos estáticos (imágenes, fuentes, etc.)
├── src/
│   ├── components/  # Componentes reutilizables
│   ├── layouts/     # Layouts de página
│   └── pages/       # Páginas del sitio

├── tailwind.config.mjs
└── package.json
```
